# 个人接单工作台

Windows首次使用提供数据目录引导：确认推荐位置、选择其他文件夹或接入包含app.db的已有账本。程序会记住位置，账本位置失效时停止启动，不会自动新建空库。

Windows：完整解压后运行 `PersonalOrderDesk.Desktop.exe`，需要系统已安装 Microsoft Edge WebView2 Runtime。后台 Web 服务保持运行，浏览器入口为 `http://127.0.0.1:5059`，共用界面为 `/Workbench`。高级导入、备份、恢复和局域网设置在 Web 设置页。

新用户的数据目录为 `%LocalAppData%/PersonalOrderDesk`，Windows主入口还将账本位置保存在客户端配置中，升级时继续识别。客户端偏好和连接凭据位于 `%LocalAppData%/PersonalOrderDesk.Client`。程序目录不存订单。已有用户升级必须保留原 `server/storage-location.json` 数据目录登记，若旧程序的登记位于根目录，应复制到新版 `server` 目录；不要把旧数据库拷到程序目录，不要用空库覆盖旧库。原登记所指数据目录也必须保留。

首次切换到新后台前，先在旧版设置页创建备份，再点击退出应用。单纯关闭桌面窗口不会停止后台服务，以便手机和浏览器继续连接。新版遇到旧服务占用5059端口会提示退出旧版，不会结束其他程序。

Android：手机发布包适用于ARM64设备，Android 7及以上；不包含x86_64模拟器库。安装APK；默认使用手机独立账本。连接PC时填写电脑设置页显示的局域网地址和访问密码。连接模式直接操作电脑账本。“预览并同步”首次建立电脑副本，切换到“电脑离线副本”可离线编辑。以后同步会比较共同版本、电脑当前内容和手机改动，先展示预览，逐处选择冲突后确认合并。手机独立账本继续单独保存。电脑数据和手机数据有明确的来源提示。

更新：在 Windows 或 Android 的“连接与数据”中检查 GitHub 发布版本，下载后校验SHA256。Windows打开压缩包后需先备份并退出后台服务，再解压到新的版本目录并保留数据登记；Android交给系统确认覆盖安装，同签名更新保留账本。请勿为更新先卸载Android应用，卸载会移除手机本地账本。手机备份按钮会生成完整ZIP保护包，可另存到应用外。恢复时先打开对应手机账本，再点“从ZIP保护包恢复”，核对单量和金额并确认；恢复前自动备份当前账本。“导出恢复前保护备份”可用于撤回恢复。

仓库和发布包只含程序，不含任何用户订单、数据库、备份、访问密码及签名私钥。发布签名密钥仅放在本地私有目录和GitHub Actions加密Secrets中。

这是三端预览版本。真实手机、各厂商安装限制和不同局域网仍需按实际环境验证。局域网HTTP不加密，只用于可信家庭/办公局域网，不要将5059端口映射到公网。


## 同步保护与回溯

同步前先备份PC账本、手机PC副本和共同版本，并保护已有的手机独立账本；两端备份失败时停止同步。预览后任一端再次修改账本，需要重新预览；合并不满足收支、日期或关联规则时事务回滚。重复提交同一同步操作不会重复记账。

手机“上次同步保护”中的导出按钮可打包两端同步前的数据库、清单和同步记录，另存到应用外。PC设置页也可按同步编号找到 `sync-before-编号.db` 与对应清单，使用已有备份预览、确认恢复流程回溯。恢复数据库会回到该时刻，请先备份恢复前的最新内容。同步保护包中 `pc-before.db` 是PC同步前账本，`phone-pc-copy.db` 是手机副本，`common-baseline.db` 是共同版本，`phone-independent.db` 是独立账本（存在时）。各文件旁的manifest说明版本；请按来源恢复，保留完整保护包。

相同金额、日期和方式的两笔新收款可能是两次真实收款，也可能重复登记。预览会提醒核对，程序不擅自删除或相加当作同一笔；需要撤销时先取消同步，在对应端撤销重复记录后重新同步。

同步中途断开时，重新连接原电脑并再次点击“预览并同步”。电脑已提交的操作会通过持久化回执识别，重新取回合并结果，不会再次记账。若手机在中断后又被修改，会保留手机数据并要求核对。电脑后台和客户端需使用同一发布版本；版本不一致时先退出旧后台，再启动配套版本。

Android系统返回键会先关闭弹窗，再从订单详情返回进入它的页面；从其他主栏目返回概览。在概览页再次返回才回到手机桌面。后台写入进行中会保留当前页面，避免中断操作。
