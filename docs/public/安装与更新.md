# 个人接单工作台

Windows：完整解压后运行 `PersonalOrderDesk.Desktop.exe`，需要系统已安装 Microsoft Edge WebView2 Runtime。后台 Web 服务保持运行，浏览器入口为 `http://127.0.0.1:5059`，共用界面为 `/Workbench`。高级导入、备份、恢复和局域网设置在 Web 设置页。

新用户的数据目录为 `%LocalAppData%/PersonalOrderDesk`，客户端偏好和连接凭据位于 `%LocalAppData%/PersonalOrderDesk.Client`。程序目录不存订单。已有用户升级必须保留原 `server/storage-location.json` 数据目录登记，若旧程序的登记位于根目录，应复制到新版 `server` 目录；不要把旧数据库拷到程序目录，不要用空库覆盖旧库。原登记所指数据目录也必须保留。

首次切换到新后台前，先在旧版设置页创建备份，再点击退出应用。单纯关闭桌面窗口不会停止后台服务，以便手机和浏览器继续连接。新版遇到旧服务占用5059端口会提示退出旧版，不会结束其他程序。

Android：安装APK；默认使用手机独立账本。连接PC时填写电脑设置页显示的局域网地址和访问密码。连接模式直接操作电脑账本。“一键同步PC副本”下载已连接电脑的数据，切换到“电脑只读副本”可离线查看。同步不合并、不覆盖手机独立账本。电脑数据和手机数据有明确的来源提示。

更新：在 Windows 或 Android 的“连接与数据”中检查 GitHub 发布版本，下载后校验SHA256。Windows打开压缩包后需先备份并退出后台服务，再解压到新的版本目录并保留数据登记；Android交给系统确认覆盖安装，同签名更新保留账本。请勿为更新先卸载Android应用，卸载会移除手机本地账本。手机备份按钮可将数据库与清单另存到应用外。

仓库和发布包只含程序，不含任何用户订单、数据库、备份、访问密码及签名私钥。发布签名密钥仅放在本地私有目录和GitHub Actions加密Secrets中。

这是三端预览版本。真实手机、各厂商安装限制和不同局域网仍需按实际环境验证。局域网HTTP不加密，只用于可信家庭/办公局域网，不要将5059端口映射到公网。
