# 3.0.0-preview.1

本版按用户要求先发布供自行测试，不标记为稳定版。

Windows / Web 改用 Tauri、Vue 与 Rust，Android 改用 Kotlin 原生界面、Room 和薄 JNI。安装包不再包含旧 .NET 运行时。

本次新增 Android 双向合并提交、逐项冲突选择、相似收支核对提醒、同步过程记录，以及提交后的本地改动保护。两端共用加密、摘要和三方合并算法；补充了任务顺序合并、跨时区父任务时间汇总、Android 任务排序与折叠。设置增加 GitHub 版本检查和安装包下载入口。

既有检查包括 Rust 算法与存储测试、Android JVM 检查，以及 MuMu 中使用隔离 Room 数据执行的下载、合并、冲突、重试与重置代次场景。最终版本仅执行编译打包，没有再次对真实账本进行同步验收；没有替换或上传用户账本。

## 使用

Windows 完整解压 ZIP 后运行 `desk-desktop.exe`。更新前在旧窗口设置中退出后台并关闭窗口，再打开新版；选择原账本目录，无需新建。

Android 安装 APK，可覆盖当前原生预览版。沿用现有开发签名，本次没有迁移正式签名；遇到签名冲突不要卸载，先备份。支持 arm64-v8a / x86_64，Android 8.0+。旧 .NET 版 App 不自动迁移。

首次连接手机先导入电脑导出的 `.deskkey`，预览并确认下载远端副本。建立共同基准后再使用合并同步；首次下载不会拿空白手机覆盖远端。

## 限制

- 本版供自行测试；建议保留独立本地备份，先用非关键记录试用。
- 尚未完成两台真实设备、真实网络中断和全部界面的集中验收。
- 版本检查只提供公开安装包下载，不自动安装或清理旧程序。
- 当前 GitHub App 的跨账号安装开放状态待确认；其他使用者仍可独立离线使用。
- 局域网直接访问新版本机控制服务、扫码、后台同步、系统通知和 iOS 尚未提供。

SHA256SUMS.txt 可用于核对附件完整性。发布包和公开源码不包含个人数据、密钥、备份或凭据。
